# Соглашение о сообщениях коммитов

[English version](COMMIT_CONVENTIONS.md)

Используйте [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) для коммитов в этом репозитории.

Пишите сообщения коммитов только на английском, включая краткое описание, основной текст и пояснения в завершающих строках.

```text
<type>[(<scope>)][!]: <description>

[body]

[footer(s)]
```

- Используйте `feat` для новой функциональности и `fix` для исправления ошибки. Другие распространённые типы включают `build`, `chore`, `ci`, `docs`, `style`, `refactor`, `perf` и `test`.
- Необязательная область (`scope`) указывает, какой части проекта касается изменение, например `kernel` или `tools`.
- Напишите краткое описание. При необходимости добавьте основной текст для контекста и завершающие строки для ссылок или других метаданных. Разделяйте эти части пустыми строками.
- Отмечайте несовместимые изменения знаком `!` перед двоеточием, завершающей строкой `BREAKING CHANGE: <description>` или обоими способами. Если используете только `!`, опишите несовместимое изменение в кратком описании коммита.

```text
build(kernel): pin Linux to 7.3.6
fix(kernel): reset PCM positions on stream reopen
docs: document code quality rules
```
